# Editor video Paatik Farm

Video menegak 9:16 (1080x1920) untuk TikTok, Reels, FB dan WhatsApp Status. Gaya tetap:
hook besar di atas, kapsyen setiap babak, label PAATIK FARM, dan kad penutup dengan harga, WhatsApp dan website.

## Cara guna
1. Buat folder `video/projek/<nama-video>/`
2. Letak klip video / gambar dalam folder tu
3. Tulis `skrip.txt` (contoh: `video/projek/contoh-kit/skrip.txt`)
4. Jalankan: `python3 video/edit.py video/projek/<nama-video>/skrip.txt`
5. Hasil: `video/projek/<nama-video>/hasil.mp4`

Pilihan dalam skrip: `MUZIK: lagu.mp3`, `SUARA_ASAL: ya`, `PENUTUP: baris1 | baris2`.
